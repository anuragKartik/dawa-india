# Davaindia Generic Pharmacy — Kanpur (Chaitanya Vihar)

Local franchise website for **Davaindia Generic Pharmacy**, Shop No 11, Chaitanya Vihar, Kalyanpur, Kanpur.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for hosting

```bash
cd web
npm run build
```

Upload the `dist/` folder to any static host (Netlify, Vercel, Cloudflare Pages, or shared hosting).

## Pages

- `/` — Home (brand, savings, categories, gallery)
- `/about` — Store & proprietor details
- `/products` — Product ranges & price comparison
- `/contact` — Phone, WhatsApp, map, enquiry form
